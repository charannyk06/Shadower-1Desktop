## **The Next Generation of AI Orchestration**

**Shadower** is a comprehensive **Agentic Orchestration Platform** built for the modern enterprise. It abandons legacy script-based automation in favor of intelligent, state-aware agents that live within your infrastructure.

Built on **Electron**, **React**, and the **Vercel AI SDK**, Shadower provides a complete, local-first desktop environment for building, testing, and deploying complex AI agents that can browse the web, execute code, and control your SaaS applications.

## **The Complete Stack**

Shadower is engineered with a modern, high-performance architecture designed for scalability and ease of deployment.

*   **Framework**: [Electron 40](https://www.electronjs.org/) + [React 18](https://react.dev/) + [Vite 5](https://vite.dev/)
*   **AI Engine**: [Vercel AI SDK](https://sdk.vercel.ai) (StreamText, Generative UI)
*   **Database**: SQLite (local, via better-sqlite3) with optional PostgreSQL
*   **ORM**: Drizzle ORM
*   **Router**: TanStack Router (hash-based for Electron file:// protocol)
*   **Styling**: Tailwind CSS v4, Framer Motion, Shadcn UI
*   **Testing**: Playwright (E2E), Vitest (Unit)

## **Key Capabilities**

### **1. 🎭 Theater Mode: The Professional Workspace**
Stop reading Markdown. **Theater Mode** transforms your chat into a professional workspace.
*   **Live App Previews**: Agents can generate and render interactive **React** and **HTML** micro-apps in real-time.
*   **Document Rendering**: Native viewing for **Excel**, **PowerPoint**, and **PDF** reports generated by agents.
*   **Immersive UI**: A glassmorphic, deep-focus environment designed for complex data review.

### **2. 🔌 Enterprise Integrations (MCP & Native Ecosystem)**
Connect your agents to the tools that power your business.
*   **Model Context Protocol (MCP)**: Plug in any standard MCP server to give your agents access to internal APIs, databases, or local files.
*   **Native Enterprise Ecosystem**: Native support for **200+ Enterprise Apps** (Salesforce, GitHub, Slack) with managed authentication.
*   **Tool Grouping**: Intelligent grouping of tools ("Gmail App", "GitHub App") prevents context window overflow.

### **3. 🛡️ E2B Sandboxed Execution**
Let your agents write and run code safely.
*   **Secure Environment**: Code runs in isolated **E2B Firecracker microVMs**, never on your main server.
*   **Data Analysis**: Agents can use Python (Pandas, Matplotlib) to process CSVs and generate visualizations.
*   **File Generation**: Automatically generate reports and "push" them to your storage or workspace.

### **4. 🎙️ Realtime Voice Assistant**
*   **Fluid Conversation**: Talk to your agents naturally using the low-latency WebSockets.
*   **Voice-Activated Workflow**: Trigger complex tool chains purely through voice commands.

## **Getting Started**

> **Prerequisite**: This project uses [pnpm](https://pnpm.io/) as the package manager.

### **Quick Start (Recommended)** 🐳

Run the entire platform (App + DB + Redis) using Docker Compose.

```bash
# 1. Install dependencies
pnpm i

# 2. Configure Environment
# The .env file is automatically created. 
# REQUIRED: Add your LLM keys (OPENAI_API_KEY, ANTHROPIC_API_KEY)
# OPTIONAL: Add Integration Keys (e.g., Enterprise App API Key) for full features.

# 3. Launch Platform
pnpm docker-compose:up
```

### **Local Development** 🚀

Run the Electron desktop app locally for rapid development.

```bash
# 1. Install dependencies
pnpm install

# 2. Start Development (Electron + Vite dev server)
pnpm dev
# Electron app launches with hot-reloading via Vite on localhost:5173
```

## **Environment Variables**

The system auto-generates a `.env` file. Key configurations:

```bash
# === Core AI ===
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-...

# === Enhancements ===
COMPOSIO_API_KEY=...       # Enable 200+ Enterprise App Integrations
E2B_API_KEY=...            # Enable Sandboxed Code Execution
EXA_API_KEY=...            # Enable Deep Web Research

# === Vector Search (Qdrant Cloud) ===
QDRANT_URL=...             # Qdrant Cloud cluster URL
QDRANT_API_KEY=...         # Qdrant Cloud API key

# === Infrastructure ===
POSTGRES_URL=postgresql://...
REDIS_URL=redis://...

# === Auth (SSO) ===
BETTER_AUTH_SECRET=...     # Generate with: npx @better-auth/cli secret
GOOGLE_CLIENT_ID=...
MICROSOFT_CLIENT_ID=...
```
